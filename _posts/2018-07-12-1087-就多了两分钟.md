# 1087: 就多了两分钟

##  [1087: 就多了两分钟](http://acm.csu.edu.cn/csuoj/problemset/problem?pid=1087) 

### Description

Yucept21和他的室友Zyn因为宿舍没电去网吧上网，上了27分钟，Cs打电话来说来电了。所以Yucept21在第29分钟下机了，上网的费用是一块钱，然后Zyn墨迹了两分钟，第31分钟下机，上机费用是2元。现在知道网吧是按照半个小时计费的，假设半个小时上机的费用是1块钱。现在给你两个时间点，要你求出上机费用和再上多少分钟最划算？（最划算是指上满这个三十分钟，比如上机一个小时四十五分钟，那么再上v = 15分钟最划算）。


### Input

输入为一行四个数字，上机时间h1,m1,下机时间h2,m2。 h是小时，m是分钟,采用24小时制。0<=h1,h2<=23

0<=m1,m2<60


### Output

输出Day \#: 后面两个数字w和v，w为费用，v描述如上，单位分钟。如果上机时间在下机时间的后面则输出"Joking"。


### Sample Input

```
1 48 3 39
20 16 22 6
23 8 1 42
```


### Sample Output

```
Day 1: 4 9
Day 2: 4 10
Day 3: Joking
```


将时间统一化成分钟题目就会简单很多了。费用每30分钟加一，让上机时间为30的倍数，这样就差不多了
```cpp
#include<iostream>
using namespace std;
int main()
{
	int cnt = 0;
	int a, b, c, d;
	while (cin >> a >> b >> c >> d)
	{
		cnt++;
		b += a * 60;
		d += c * 60;//转化成分钟就不用考虑小时的问题了
		if (d < b)
		{
			printf("Day %d: Joking\n", cnt);
			continue;
		}
		int pay;
		pay = (d - b) / 30 + ((d - b) % 30 ? 1 : 0);//判断上机时间是否为30的倍数，如果有余数说明需要费用多加1
		int time = pay  * 30 - (d - b);//支付pay元的最大上机时间减去现在的上机时间就是剩下的应该上机的时间
		printf("Day %d: %d %d\n", cnt, pay, time);
	}
	return 0;
}
```
