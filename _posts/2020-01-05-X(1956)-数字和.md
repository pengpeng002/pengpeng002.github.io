# X(1956): 数字和

### X\( [1956](http://acm.csu.edu.cn/csuoj/problemset/problem?pid=1956) \): 数字和

Time Limit: 1 Sec    Memory Limit: 128 Mb    Submitted: 71    Solved: 25

---

### Description

长者对小明施加了膜法，使得小明每天起床就像马丁的早晨一样。 今天小明早上起来后发现身体虽然变小,头脑依旧不变变傻。

他有一条纸带，上面有n个数字，第i个数字为 *A* *i* 。 他想把纸带选三个位置p1, p2, p3\(p1 < p2 < p3\)把纸带剪成4个每条长度至少为1的4条纸带。 分别为\[1, p1\-1\], \[p1\+1, p2\-1\], \[p2\+1, p3\-1\], \[p3\+1, n\],使得4个部分中数字之和相等。


### Input

多组输入 每组测试数据第一行输入一个 *n* \(7 ≤ *n* ≤ 105\) 第二行n个数，第i个数为 *A* *i* \(0 ≤ *A* *i* ≤ 109\)，表示第i个数


### Output

输出字典序最小的p1,p2,p3 如果不存在这种操作，输出\-1


### Sample Input

```html
7
6 2 6 2 6 2 6
7
1 2 3 4 5 6 7
```


### Sample Output

```html
2 4 6
-1
```



思路：定义三个数将区间分四份，利用尺取法使每个区间的和都是相等的。具体的看代码注释

[尺取基本介绍](https://blog.csdn.net/acmer_sly/article/details/59524223) 

```cpp
#include<iostream>
using namespace std;
const int MAX = 1e5+5;
int a[MAX], b[MAX];
void aa(int n)
{
	int a1,a2,a3;
	a1=2,a2=4,a3=6;
	for (a1=2;a1<n-4;a1++)//a1最大只能为n-5，再大就会使后面的区间不存在了
	{
		a2=max(a2, a1+2);//最少要比a1大二，否则第二个区间就会为空
		while (a2 <= n && b[a2-1] - b[a1] < b[a1-1])a2++;
		//保证第二个区间的和会大于或等于第一个区间的和，并且a2合法
		if(a2 >= n || b[a2-1] - b[a1] > b[a1-1])continue;
		//若第二个区间比第一个区间的和要大或a2不合法，就需要重新开始
		a3=max(a3, a2+2);//后面同理
		//执行到此处，则第一区间和第二区间的和相等
		while (a3 <= n && b[a3-1] - b[a2] < b[a1-1])a3++;
		if(a3 >= n || b[a3-1]- b[a2] > b[a1-1])continue;
		if(b[n] - b[a3] == b[a1-1])//能执行到此处说明前三个区间的和是相等的
		{
			cout << a1 << " " << a2 << " " << a3 << endl;return;
		}
	}
	cout << "-1\n";//若执行到此处，说明已经不可能有符合题意的划分了
}
int main()
{
	int n;
	while (scanf("%d",&n)==1)
	{
		for (int i =1;i <=n ; i++)
		{
			scanf ("%d",&a[i]);
			b[i]=b[i-1]+a[i];//b[i]记录前i项的和
		}
		aa(n);
	}
	return 0;
}
```
