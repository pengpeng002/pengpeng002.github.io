# 力扣每日一题 3255. 长度为 K 的子数组的能量值 II

今天的数据范围就用昨天那个O\(n\)复杂度的解法就可以了

把数组分成一段一段连续上升的子数组，用pre记录当前这段连续上升的子数组的起点，然后用当前位置减去起点位置就是连续上升的长度，大于k时就可以记录下来。如果遇到不满足连续上升的，就更新一下pre的位置。

```cpp
class Solution {
public:
    vector<int> resultsArray(vector<int>& nums, int k) {
        vector<int> ans;
        if (k==1) return nums;
        int len = nums.size();
        int pre=-1;
        for (int i=1; i<len; i++)
        {
            if (nums[i] - nums[i-1] != 1) pre=i-1;
            if (i-pre >= k)
            {
                ans.push_back(nums[i]);
            }
            else if (i>=k-1)
            {
                ans.push_back(-1);
            }
        }
        return ans;
    }
};
```
