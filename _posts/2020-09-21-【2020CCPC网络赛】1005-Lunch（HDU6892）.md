# 【2020CCPC网络赛】1005 Lunch（HDU6892）

[题目链接](http://acm.hdu.edu.cn/showproblem.php?pid=6892) 

题意：有n块巧克力，每块长度为Li，两个人轮流选某一块，将其均分为x\(x\!=1\)块，每块长度为整数。无法进行操作者输。

思路：首先我们知道如果只有一块，则一定是先手必胜状态。因为先手可以把这一块分成L块长度为1的。但如果先手不是一次性分成长度为1的，那么先手是不是一定会变成必败态呢？当然不是。考虑长度为4的情况，如果将4分成2个2，最后还是先手必胜。其实，只要分成的是偶数块，都不会导致状态交换。那如果是分成奇数块呢？那就会了。比如将6分成3个2，最后先手由必胜变成了必败态。

所以我们可以知道，分解出来的块数（或者说增加的操作次数）的奇偶性是交换胜败态的关键。为什么会这样？我们可以这样理解，因为拆分出来的每一堆都是一样大的，那么可以认为：增加偶数堆只是在通往胜利的道路上走了几步额外的路而已。比如两堆一样大的，则后手可以和先手做完全一样的动作，以保证胜败状态不会发生改变，两堆及以上同理。而奇数堆就相当于多加了一堆。

那么我们可以简单的将分解出奇数堆看成单个的一堆，偶数堆则可以直接当成是1忽略掉，前面已经说过这样并不会对结果造成影响。这样，原本看上去无比复杂的分解树就被简化成了一条分解链。而每次操作就相当于是在这条链上截掉任意长的链。比如9可以视为一条长度为2的链（9\->3\->1）。

这时，我们重新回顾一下题目，题目就变成了：有n条链，每条长度为Li，两个人轮流选一条，将其截取任意长，不可不截，无法截取者（即每条的长度都为0）输。有没有觉得有点似曾相识的感觉？对，这不就是把nim博弈换了个说法吗。那我们可以套用nim博弈的解题方法来写了。

一个小问题，我怎么确定这条链的长度呢？答案是 这个数的奇数质因子的个数加上是否有偶数因子。自己想一想为什么。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int maxn=5e4+2;//1e5直接超时 
bool vis[maxn];
int pri[maxn];
int cnt=0, t, n;
typedef long long ll;
void init()
{
	memset(vis,0,sizeof(vis));
	vis[1]=vis[0]=1;
	for(int i=2;i<maxn;i++)
	{
		if(!vis[i])
		{
			pri[cnt++]=i;
			if(i > maxn/i) continue;
			for(int j=i*i;j<maxn;j+=i)
			{
				vis[j]=1;
			}
		}
	}
}
int len(int x)
{
	int ans=0, f=0;
	for(int i=0;i<cnt;i++)
	{
		int &t=pri[i];
		if(x < t) break;
		while(x%t == 0)
		{
//			if(t==2) f=1;
//			else ans++;
			t==2 ? f=1 : ans++;
			x/=t;
		}
	}
	if(x>=2) ans++;
	return ans+f; 
}
int main()
{
	init();
	scanf("%d",&t);
	while(t--)
	{
		scanf("%d",&n);
		int ans=0,x;
		for(int i=0;i<n;i++)
		{
			scanf("%d",&x);
			ans ^= len(x);
		}
		if(ans==0) puts("L");
		else puts("W");
//		printf("%c\n", "LW"[ans==0]);
	}
}
```
