# 力扣每日一题打卡 3180. 执行操作可获得的最大总奖励 I

给你一个整数数组 rewardValues，长度为 n，代表奖励的值。

最初，你的总奖励 x 为 0，所有下标都是 未标记 的。你可以执行以下操作 任意次 ：

从区间 \[0, n \- 1\] 中选择一个 未标记 的下标 i。
如果 rewardValues\[i\] 大于 你当前的总奖励 x，则将 rewardValues\[i\] 加到 x 上（即 x = x \+ rewardValues\[i\]），并 标记 下标 i。
以整数形式返回执行最优操作能够获得的 最大 总奖励。

这题目其实是个非常明显的背包问题，只不过是稍微改了一下的0\-1背包问题，所以很明显是个动态规划\(dp\)题，但可惜我太久没写题目了，已经不会dp了。（ ~~不，明明是因为晚上的时候脑子不清醒转不动~~ ）

最后是稍微借助了一下题目下方的提示才写出来的。

dp嘛，能找到状态转移方程，题目就算解决一半了，所以重点在于我们的状态转移方程要怎么确定。

我们可以设计dp\[i\]\[j\]=1表示我们有 i 个物品，可以获得 j 的奖励。那么，最后要求的就是dp\[n\-1\]那一行最大的满足dp\[n\-1\]\[j\]=1的 j 。

那dp\[i\-1\]怎么的值要怎么转移到dp\[i\]呢？如果我们不选第i个物品，那肯定dp\[i\]=dp\[i\-1\]。而如果我们要选第i个物品呢？我们知道，只有手上的奖励值比rewardValues\[i\]
的值小的时候，我们才可以选择，在这种情况下，dp\[i\]\[j\] = dp\[i\-1\]\[j\- rewardValues\[i\] \]。
这样，我们就可以把最核心的部分写出来了

```cpp
dp[0][0]=1;
for (int i=1; i<len; i++) //为了方便处理，我在数组最前方插入了一个0，让数组从1开始计数
{
    int x=rewardValues[i];
    for (int j=0; j<maxx*2; j++) dp[i][j] = dp[i-1][j];
    for (int j=0; j<x; j++)
    {
        if (dp[i-1][j]==1) dp[i][j+x]=1;
    }
}
```

顺便，我们假设奖励的最大值为m，那么如果我们要选择m，则我们前面的所有操作的总奖励一定是小于m的。也就是说我们总共可以获得的最大奖励是小于2m的。
同理，如果我们要选择一个奖励值为x的物品，我们之前的操作的奖励和一定小于x。所以，我们每次选择的奖励值其实是单调递增的。
那么，我们可以先对输入的数据进行一次从小到大排序。
那我可以偷懒不排序吗？答案是不行。
这题目可不能直接当作01\-背包问题处理，两者是有区别的。这个题如果不排序，状态转移方程\( ~~看似~~ \)正确，答案可能也会错。（顺序会影响你得到的结果，也就是顺序不同，你得到的答案可能会不同，也就是错误的答案。）
原因在于： 只有 rewardValues\[i\] 大于当前的总奖励 x，才能获取rewardValues\[i\]。 必须按照rewardValues\[i\]值从小到大考虑，如果不这么做，你这次选了一个较大的值，那后面比它小的就已经不能选了。而背包问题就不存在这个问题。
最终代码如下

```cpp
class Solution {
public:
    int maxTotalReward(vector<int>& rewardValues) {
        // const int maxn=2000+5;
        rewardValues.insert(rewardValues.begin(), 0);
        sort(rewardValues.begin(), rewardValues.end());
        const int len = rewardValues.size();
        int maxx = rewardValues[len-1];
        int dp[len+5][maxx*2];
        for (int i=0; i<len; i++)
        {
            for (int j=0; j<maxx*2; j++)
            {
                dp[i][j] = 0;
            }
            dp[i][0]=1;
        }
        dp[0][0]=1;
        for (int i=1; i<len; i++)
        {
            int x=rewardValues[i];
            for (int j=0; j<maxx*2; j++) dp[i][j] = dp[i-1][j];
            for (int j=0; j<x; j++)
            {
                if (dp[i-1][j]==1) dp[i][j+x]=1;
            }
        }
        for (int i=maxx*2-1; i>=0; i--)
        {
            if (dp[len-1][i] == 1) return i;
        }
        return 0;
    }
};
```

时间复杂度O\(2 *m* n\)\.其中 n，m 分别是 rewardValues 的长度和最大值
空间复杂度O\(2 *m* n\+n\)
接下来就是找一下有没有可能能够优化的地方了。
首先，我们可以试着把这个二维数组压缩到一维数组，毕竟我们最终的返回值要用到的只有dp\[n\-1\]那一行。
状态转移方程：
对于 i∈\[x,2x−1\]，dp\[i\] = dp\[i−x\] ∣ dp\[i\]

```cpp
class Solution {
public:
    int maxTotalReward(vector<int>& rewardValues) {
        // const int maxn=2000+5;
        vector<int> &vec=rewardValues; //偷个懒，取下别名
        vec.insert(vec.begin(), 0); // 在头部查个0，方便从1开始遍历
        sort(vec.begin(), vec.end()); // 排序
        vec.erase(unique(vec.begin(), vec.end()), vec.end()); // 去重，少量节省时间

        const int len = vec.size();
        const int ma = vec[len-1];
        if (vec[len-2] == ma-1) return ma*2 - 1; // 特判，在这种情况下，要返回的结果已经确定了
        vector<int> dp(ma*2, 0);
        dp[0]=1;
        for (int i=1; i<len; i++)
        {
            for (int j=0; j<vec[i]; ++j)
            {
                dp[j+vec[i]] |= dp[j];
            }
        }
        for (int i=ma*2-1; i>=0; i--)
        {
            if (dp[i]) return i;
        }

        return 0;
    }
};
```

dp\[j\+vec\[i\]\] |= dp\[j\];是一个小技巧，如果不用或运算，这句需要改成

```cpp
if (dp[j] || dp[j+vec[i]]) dp[j+vec[i]]=1;
```

或者

```cpp
if (dp[j]) dp[j+vec[i]]=1;
```

那么，这个dp还有可能再继续优化吗？当然是可以的。
既然dp\[i\]的值只有0和1，那么完全没必要用一个int去存，显然换成bool比用int合适。但如果dp\[i\]能只用一个bit是最好的。理论上肯定是可行的，只不过如果要实现起来特别麻烦。
这时候，就轮到bitset出场了。之前没有接触过的可以自行去了解一下。它可以简单当初一个每一位只占一个bit的数组来用，而且还支持各种位运算，非常方便。

```cpp
class Solution {
public:
    int maxTotalReward(vector<int>& rewardValues) {
        // const int maxn=2000+5;
        vector<int> &vec=rewardValues; //偷个懒，取下别名
        vec.insert(vec.begin(), 0); // 在头部查个0，方便从1开始遍历
        sort(vec.begin(), vec.end()); // 排序
        vec.erase(unique(vec.begin(), vec.end()), vec.end()); // 去重，少量节省时间

        const int len = vec.size();
        const int ma = vec[len-1];
        if (vec[len-2] == ma-1) return ma*2 - 1; // 特判，在这种情况下，要返回的结果已经确定了
        
        #define blen 4000
        bitset<blen> bit(1);
        for (int i=1; i<len; i++)
        {
            for (int j=0; j<vec[i]; ++j)
            {
                if (bit[j]) bit[j+vec[i]] = 1;
            }
        }
        for (int i=ma*2-1; i>=0; i--)
        {
            if (bit[i]) return i;
        }

        return 0;
    }
};
```

不过，既然bitset可以支持位运算，那为什么不用起来呢？内层的for循环实际上就一个移位加上或就可以了。

```cpp
const int shift = blen-vec[i];
bit |= bit<<shift>>shift<<vec[i];//移位是为了把所有>= vec[i]的位全部置0
```

最终代码

```cpp
class Solution {
public:
    int maxTotalReward(vector<int>& rewardValues) {
        // const int maxn=2000+5;
        vector<int> &vec=rewardValues; //偷个懒，取下别名
        vec.insert(vec.begin(), 0); // 在头部查个0，方便从1开始遍历
        sort(vec.begin(), vec.end()); // 排序
        vec.erase(unique(vec.begin(), vec.end()), vec.end()); // 去重，少量节省时间

        const int len = vec.size();
        const int ma = vec[len-1];
        if (vec[len-2] == ma-1) return ma*2 - 1; // 特判，在这种情况下，要返回的结果已经确定了
        
        #define blen 4000
        bitset<blen> bit(1);
        for (int i=1; i<len; i++)
        {
            for (int j=0; j<vec[i]; ++j)
            {
                const int shift = blen-vec[i];
				bit |= bit<<shift>>shift<<vec[i];
            }
        }
        for (int i=ma*2-1; i>=0; i--)
        {
            if (bit[i]) return i;
        }

        return 0;
    }
};
```

时间复杂度O\(n\*m/w\)
空间复杂度O\(n\+m/w\)
