# c++与批处理结合对文件批量重命名

本人沉迷动漫无法自拔，由于网络问题，我是先下载后再看的。相信不少朋友都遇到过类似的问题，网上下的文件名太长或者没什么用。想重命名，但问题是，如果文件少倒还好，万一文件有几百个，一个个重命名不得累死。如果能写个程序自动进行重命名该多好，这时候我就想到用批处理了。这种事用批处理最方便不过了，遍历文件夹内的文件，然后重命名。可如果要截取的是文件名中间的一部分，用批处理就会很麻烦了。比如下面这种“ひぐらしのなく頃に·礼01「羞晒し編」\.mp4”，我嫌太长了，我只要一个“01”就够了，用批处理也可以做到，听大佬说可以考虑用正则匹配，问题是正则我不会啊。像这种情况，用C语言就会简单很多，然而用C语言对文件进行遍历我不太会。这时我想到把c和批处理结合起来。问题果然简单多了。

这里是批处理部分的代码。

```
::@echo off
::遍历文件所在路径下所有的MP4文件
for %%i in (*.mp4) do (
rem 调用re.exe文件，将文件名作为参数传进去
re.exe %%i
)
::冻结屏幕，以免一闪而过，方便看过程
pause
```

c\+\+部分代码

```cpp
#include <stdio.h>
#include <string>
#include <iostream>
using namespace std;
//ひぐらしのなく頃に·礼01「羞晒し編」.mp4
int main(int argc,char **argv)
{
	if(argc==2)
	{
		//printf("%c %c\n",argv[1][22],argv[1][23]);
		char a=argv[1][22],b=argv[1][23];//取出文件名内0和1字符
		string name="寒蝉鸣泣礼";//字符串拼接，不会c++的string的同学可以用C语言进行字符串拼接
		name+=a;
		name+=b;
		name+=".mp4";
		//cout<<name<<endl;
		rename(argv[1],name.c_str());//重命名
	}
}
```

但遇到文件名有空格的情况，c\+\+这部分代码运行就会出问题，因为参数会以空格分开。虽然用C语言可以做到文件名的还原，代码也不长，但我更愿意选择在传递参数之前将空格去掉。

```
setlocal enabledelayedexpansion
set "str= "
for /f "delims=" %%i in ('dir /b *.mp4') do (
set "var=%%i"
ren "%%i" "!var:%str%=!"
)
pause
```

将上面的代码保存为bat文件，双击就可以将空格去掉了。只要三个文件结合，大部分情况都可以解决。不过瑕疵还是有一些的，目前发现两个，一是如果文件名过长，可能无法正确执行去空格部分代码。这种情况好像只能选择不去除空格。二是文件重命名后，文件可能会被自动排序到未重命名文件的后面，造成二次重命名。这种情况可以在cpp部分加个if特判
