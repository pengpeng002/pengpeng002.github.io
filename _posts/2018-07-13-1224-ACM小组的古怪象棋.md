### Description

ACM小组的Samsara和Staginner对中国象棋特别感兴趣，尤其对马（可能是因为这个棋子的走法比较多吧）的使用进行深入研究。今天他们又在 构思一个古怪的棋局:假如Samsara只有一个马了，而Staginner又只剩下一个将，两个棋子都在棋盘的一边，马不能出这一半棋盘的范围，另外这 一半棋盘的大小很奇特\(n行m列\)。Samsara想知道他的马最少需要跳几次才能吃掉Staginner的将\(我们假定其不会移动\)。当然这个光荣的任 务就落在了会编程的你的身上了。


### Input

每组数据一行，分别为六个用空格分隔开的正整数n,m,x1,y1,x2,y2分别代表棋盘的大小n,m,以及将的坐标和马的坐标。（1<=x1,x2<=n<=20,1<=y1,y2<=m<=20,将和马的坐标不相同）


### Output

输出对应也有若干行，请输出最少的移动步数,如果不能吃掉将则输出“\-1”\(不包括引号\)。


### Sample Input

```
8 8 5 1 4 5
```


### Sample Output

```
3
```



很标准的广度优先遍历问题啊。从马的初始坐标开始进行遍历，最后得到的结果肯定是最少的，至于原因还是自己解决吧，我只是知道有这个道理，原因我就说不清了。在CSU上刷题的时候我才真正感受到了数据结构的重要，真的好后悔上课的时候没认真。仅26个入门题我都已经看到了好多好多数据结构方面的了。

#include<iostream>
#include<queue>
using namespace std;
struct node
{
	int x, y, z;//xyz分别记录这个点的xy坐标和到这个点的步数
};
const int maxn = 25;
int sx, sy, mx, my, m, n;//将的xy坐标，马的xy坐标，题意中的mn
const int dir[8][2]={{2,1},{1,2},{-1,2},{-2,1},{-2,-1},{-1,-2},{1,-2},{2,-1}};//马能走的周围的八个位置
bool visit[maxn][maxn];//记录是否已经走过
bool check(node a)//检查这个点是否合法
{
	return (a.x >=0 && a.x <n && a.y >= 0 && a.y < m);
}
int bfs()
{
	queue<node> q;
	node m, temp, next;
	m.x = mx;//马的相关信息
	m.y = my;
	m.z = 0;
	q.push(m);//马的位置应该是最先查找
	visit[mx][my] == 1;//标记此点是已经走过的
	while (!q.empty())//如果q为空说明马在棋盘上能走的所有位置都已经走过了
	{
		temp = q.front();//取队头元素
		q.pop();
		if (temp.x == sx && temp.y == sy)//判断是否是将的位置
		{
			return temp.z;
		}
		for (int i = 0; i < 8; i++)//周围的八个点
		{
			next.x = temp.x + dir[i][0];
			next.y = temp.y + dir[i][1];//到下一个点
			if (next.x == sx && next.y == sy)//判断，虽然用处不大，可以不要
			{
				return temp.z + 1;
			}
			if (check(next) && !visit[next.x][next.y])
			{
				next.z = temp.z + 1;
				q.push(next);
				visit[next.x][next.y] = 1;
			}
		}
	}
	return -1;
}
int main()
{
	while (cin >> n >> m >> sx >> sy >> mx >> my)
	{
		int c = bfs();
		cout << c << endl;
	}
	return 0;
}
