# S(1022): 菜鸟和大牛

### S\( [1022](http://acm.csu.edu.cn/csuoj/problemset/problem?pid=1022) \): 菜鸟和大牛

[](http://acm.csu.edu.cn/csuoj/problemset/summary?pid=1022) [](http://acm.csu.edu.cn/csuoj/problemset/summary?pid=1022) Time Limit:1 SecMemory Limit:128 MbSubmitted:101Solved:62---

### Description

blue和AutoGerk是好朋友。他们的相同点是都喜欢研究算法，不同点是AutoGerk已是大牛而blue还是菜鸟。blue经常拿一些自以为很难的问题去问AutoGerk，想难倒他，但是每次AutoGerk都能轻而易举地做出来。就在上个礼拜的星期天下午，AutoGerk正在玩游戏，blue又拿着他的问题来了。AutoGerk一看，依然是如此简单。AutoGerk很想玩他的游戏，但是又不想冷落朋友。于是他介绍你，同样是大牛级的人物，给blue，来回答他的问题。

blue的问题如下：

一个由n行数字组成的三角形，第i行有2i\-1个正整数（小于等于1000），如下：

```
      3
    7 1 4
  2 4 3 6 2
8 5 2 9 3 6 2
```

要求你用笔从第1行画到第n（0 < n ≤ 100）行，从当前行往下画的时候只能在相邻的数字经过，也就是说，如果从一行的一个数往下画，只能选择其左下或者正下或者右下三个数中的一个（如果存在的话），把所有被画起来的数字相加，得到一个和，求能得到的最大的和的值是多少。

上例中能得到的最大的和为3 \+ 7 \+ 4 \+ 9 = 23\.


### Input

第一行，一个自然数T，表示总共给出的三角形数，对于每一个三角形，首先给出一个自然数n，表示将输入的三角形有n行。接下来有n行，第i行有2i\-1个数字，


### Output

对于每个三角形，输出一个数，即能得到的最大的和。


### Sample Input

```
2
2
1
1 2 3
4
3
7 1 4
2 4 3 6 2
8 5 2 9 3 6 2
```


### Sample Output

```
4
23
```



和杭电2084挺像的，只不过多了一种选择而已。方法是一样的，从最下面开始往上面找。

状态转移方程：a\[i\]\[j\] \+= max\(a\[i\+1\]\[j\],a\[i\+1\]\[j\+1\],a\[i\+1\]\[j\+2\]\)。

如果没有接触过动态规划之类的题可能会觉得不太好理解，可以参考下杭电2084的解法，这题算是那题的进阶版


```cpp
#include<iostream>
using namespace std;
int a[205][205];
int maxn(int a, int b, int c)
{
	int t = a > b ? a : b;
	return t > c ? t : c;
}
int main()
{
	int t;
	cin >> t;
	while (t--)
	{
		int n;
		cin >> n;
		for (int i = 0; i < n; i++)
		{
			for (int j = 0; j < i * 2 + 1; j++)
			{
				cin >> a[i][j];
			}
		}
		for (int i = n - 1; i >= 0; i--)
		{
			for (int j = 0; j <= i * 2 - 1; j++)
			{
				int w = maxn(a[i][j], a[i][j + 1], a[i][j + 2]);
				a[i - 1][j] += w;
			}
		}
		cout << a[0][0] << endl;
	}
	return 0;
}
```
