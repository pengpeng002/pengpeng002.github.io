### Description

输入一个四个数字组成的整数n,你的任务是数一数有多少种方法,恰好修改一个数字,把它 变成一个完全平方数\(不能把首位修改成0\)。比如n=7844,有两种方法:3844=62^2和7744=88^2。


### Input

输入第一行为整数 T \(1<=T<=1000\),即测试数据的组数,以后每行包含一个整数 n \(1000<=n<=9999\)。


### Output

对于每组数据,输出恰好修改一个数字,把 n 变成完全平方数的方案数。


### Sample Input

```
2
7844
9121
```


### Sample Output

```
Case 1: 2
Case 2: 0
```
