# 力扣每日一题 812. 最大三角形面积

数据范围只有50，显然直接暴力就行了，确实简单题

但它又没那么的简单，难点全在怎么算三角形面积上，如果不靠网上搜，我只能说我不会

在这里记几个公式

海伦公式： $$
S = \sqrt{p(p-a)(p-b)(p-c)}
$$

其中，abc为三角形的三条边长，p为三角形的半周长，即 $$
p=\frac{a+b+c}{2}
$$

这个公式在已知三边长的时候最好用，这个题的话就不是那么合适了

行列式公式： $$
S=\frac{1}{2}|x_1(y_2-y_3)+ x_2(y_3 - y_1) + x_3(y_1 - y_2)|
$$

鞋带公式： $$
S=\frac{1}{2}|x_1y_2 + x_2y_3 + x_3y_1 - x_2y_1 - x_3y_2 - x_1y_3|
$$

向量叉积公式： $$
S = \frac{1}{2}|(x_2 - x_1)(y_3 - y_1) - (x_3 - x_1)(y_2 - y_1)|
$$

公式敲的不保证准确，请以图片和代码里的为准

后面三个公式来自评论区

```cpp
double largestTriangleArea(vector<vector<int>>& points) {
        double ans = 0.0;
        int len = points.size();
        for (int i=0; i<len; ++i)
        {
            for (int j=i+1; j<len; ++j)
            {
                for (int k=j+1; k<len; ++k)
                {
                    int x1=points[i][0], y1=points[i][1];
                    int x2=points[j][0], y2=points[j][1];
                    int x3=points[k][0], y3=points[k][1];

                    // double S = fabs(x1*(y2-y3)+x2*(y3-y1)+x3*(y1-y2))/2;
                    // double S = fabs((x2-x1)*(y3-y1)-(x3-x1)*(y2-y1))/2;
                    // double S = fabs(((x1*y2)+(x2*y3)+(x3*y1))-((x2*y1)+(x3*y2)+(x1*y3)))/2;
                    double a = sqrt(pow(x1 - x2, 2) + pow(y1 - y2, 2));
                    double b = sqrt(pow(x2 - x3, 2) + pow(y2 - y3, 2));
                    double c = sqrt(pow(x1 - x3, 2) + pow(y1 - y3, 2));
                    double p = (a + b + c) / 2;
                    double S = sqrt(p * (p - a) * (p - b) * (p - c));
                    ans = max(ans, S);
                }
            }
        }
        return ans;
    }
```
