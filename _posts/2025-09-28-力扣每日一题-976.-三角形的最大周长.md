# 力扣每日一题 976. 三角形的最大周长

感觉今天脑子转不过来，还想着暴力，结果超时了。

但最后发现确实特别简单，从大到小排序之后，最大的一定是连续的三个，所以就只要遍历一遍找到能构成三角形的就可以了。面积不为0这一点其实根本用不到，因为任意三条边只要能构成三角形，面积就不可能为0

```
class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        reverse(nums.begin(), nums.end());
        int len = nums.size();
        for (int i=0; i<len-2; ++i)
        {
            if (nums[i]-nums[i+1] < nums[i+2]) return nums[i]+nums[i+1]+nums[i+2];
        }
        return 0;
    }
};
```
