# 1781: 阶乘除法

### Description

输入两个正整数n, m,输出n\!/m\!,其中阶乘定义为n\!= 1\*2\*3\*\.\.\.\*n \(n>=1\)。 比如,若n=6, m=3,则n\!/m\!=6\!/3\!=720/6=120。

是不是很简单?现在让我们把问题反过来:输入k=n\!/m\!,找到这样的整数二元组\(n,m\) \(n>m>=1\)。

如果答案不唯一,n应该尽量小。比如,若k=120,输出应该是n=5,m=1,而不是n=6,m=3,因为5\!/1\!=6\!/3\!=120,而5<6。







### Input

输入包含不超过 100 组数据。每组数据包含一个整数 k \(1<=k<=10^9\)。


### Output

对于每组数据,输出两个正整数 n 和 m。无解输出"Impossible",多解时应让 n 尽量小。


### Sample Input

```
120
1
210
```


### Sample Output

```
Case 1: 5 1
Case 2: Impossible
Case 3: 7 4
```



无解的情况只有一种，就是k=1，因为mn均为正数，所以不能考虑0\.其他的都是能做到的。因为k\!/\(k\-1\)\!=k,不管k怎么取都行，都是一定成立。但因为n要尽可能小，所以还是需要将n从1开始进行循环计算。

不过把每个数的阶乘都求出来进行遍历就别想了，k太大，面对阶乘long long也存不下几个。但由于阶乘的性质，所以m\!/n\!=m\*\(m\-1\)\*\(m\-2\)\*\.\.\.\*\(n\+1\)。具体看代码吧，不懂再问咯\.如果觉得注释不够详细还请见谅


```cpp
#include<iostream>
using namespace std;
int main()
{
	int n;
	int cas = 0;
	while (cin >> n)//题目是用的k，但我习惯性用了n
	{
		cas++;//记录测试组数
		if (n == 1)//因为题目里不能出现0的阶乘，所以n=1是无解的
		{
			printf ("Case %d: Impossible\n", cas);
			continue;
		}
		int flag = 0;
		for (int i = 1; i * i <= n; i++)//如果i*i>n，那么i*j也一定大于n了,因为j从i+1开始
		{
			long long int sum = 1;//一定要用long long，用int会溢出的，一旦溢出，sum就会变成负数，导致超时，所以要用long long
			//在32位Windows系统中，long int和int的最大值是相同的，所以用long int和用int一样会溢出
			//对此有疑问的可以看头文件climits,INT_MAX就是int的最大值
			int j = 0;
			for ( j = i + 1; sum < n; j++)//j的最终值无法确定，只要sum<n就可以一直乘下去
			{
				sum *= j;
			}
			if (sum == n)
			{
				printf ("Case %d: %d %d\n", cas, j - 1, i);//因为j在最后多加了一次，所以j要减1
				flag = 1;
				break;
			}
		}
		if (!flag)
		{
			printf ("Case %d: %d %d\n", cas, n, n - 1);
		}
	}
	return 0;
}
```
